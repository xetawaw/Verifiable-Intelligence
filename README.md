# Verifiable Intelligence — Interactive Animation

Single-file interactive HTML animation: an RL agent proposes proof tactics,
a Lean-style verifier accepts/rejects each line, the exact reward updates the
policy, and the FunSearch evolutionary loop runs in parallel.

No build step — `index.html` runs standalone in any browser.

**Deploy:** import this repo into Vercel (zero config, static site) or open
`index.html` directly.
