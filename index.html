STEP 03
VERIFY

An exact signal r ∈ {−1, +1} — no noise, no human, no proxy. Acceptance is the definition of success.

LEARN
Policy-gradient update π ← π + η·r·∇log π — tactics that verify become more likely.

HOW TO READ THIS / 10-second guide

✕Coral star — rejected: that tactic is demoted in the policy (watch the agent's bars shift).

○Gold ring — the kernel mid-check. All five stars mint = proof verified → reward +1 → policy reinforced.
